## 📌 Sobre o projeto

O **Habits** é um app para ajudar a rastrear os hábitos. Cada dia vira uma coluna, e é só marcar os hábitos que você cumpriu.

### 🚀 Funcionalidades

- Registrar o dia atual com o botão **Registrar o meu dia**
- Aviso quando o dia já foi incluído
- Marcar e desmarcar cada hábito por dia
- Salvamento automático no navegador, então os dados continuam lá quando você volta

### 🗓 Hábitos acompanhados

| Ícone | Hábito |
| --- | --- |
| 📘 | Estudar |
| 🏋️‍♀️ | Exercícios |
| 💧 | Beber água |
| 👩‍💻 | Programar |
| 😴 | Dormir |

## ⚙️ Como executar o projeto

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/lunajulia107/nlw-setup.git
```

### 2️⃣ Abrir no navegador

Dê dois cliques no arquivo `index.html`. Pronto! 🎉

> [!TIP]
> Os hábitos ficam salvos no `localStorage` do navegador. Se limpar os dados do navegador, o histórico também é apagado.
